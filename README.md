# Posts Loader

Загрузка и отображение постов с публичного API через `fetch`.

## Задача
С помощью `fetch` получить список постов с публичного API и отобразить их на странице:

- получить данные с `https://jsonplaceholder.typicode.com/posts`;
- отобразить первые 5 постов (заголовок и текст);
- пока данные грузятся — показать «Загрузка…»;
- при ошибке — показать сообщение об ошибке.

## Что реализовано
- Запрос к API через `fetch` и цепочку промисов `.then().catch()`.
- Проверка `response.ok` — ошибки уровня HTTP (404, 500) обрабатываются как ошибки, а не как успех.
- Два `.then`: первый — для разбора `Response`, второй — для работы с готовыми данными.
- Отображение первых 5 постов через `slice(0, 5)` (без мутации исходного массива).
- Разделение состояний: «Загрузка…» / успех / ошибка — всё в одном контейнере.
- Очистка контейнера перед рендером — «Загрузка…» не остаётся вместе со списком.
- Обработка ошибок в `.catch` с выводом сообщения пользователю.
- Вставка текста через `textContent` — защита от XSS, так как данные приходят извне.

## Технологии
- HTML
- JavaScript (ES6+, промисы, `fetch` API)
- Без фреймворков и библиотек.

## Как запустить
1. Скачать или клонировать репозиторий.
2. Открыть `index.html` в браузере.

Требуется подключение к интернету — данные загружаются с публичного API.


## Структура проекта
```
├── index.html   — разметка: контейнер для постов
└── app.js       — запрос к API, рендер, обработка состояний и ошибок
```
